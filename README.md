# **Overview**
The set of VhClass scripts provide methods to preprocess antibody variable heavy chain sequences (input .fasta file with labels) and train a classification model that predicts human-like of camelid-like class of a given sequence. The scripts for training, data preprocessing and prediction generation are included. The trained model is probided as the .joblib file (however, one can retrain the model using provided scripts and training data) 

Additionally, in this work we compare scores generated by AbNativ tool to the predictions generated by VhClass tool. The script to convert AbNativ scores into binary labels and calculate classification metrics are also provided.
# **Dependencies**
- sklearn
- joblib
- pandas
- numpy
- argparse

Custom functions:
- _assess_peform_stats.py_  (calculate classification metrics for generated predictions or validation data with labels)
- _encode_kmer.py_ (encode aminoacid sequence as a feature vector of k-mers)
- _read_fast_to_df.py_ (read fasta file into a pandas data frame)
- _Make_OAS_human_train_set.py_ (preprocess human sequences used for model training and save as fasta file)
- _Make_OAS_camelid_train_set.py_ (preprocess camelid sequences used for model training and save as fasta file)
- _randomize_and_mix_OAShum_cam.py_ (make a fasta file from the human and camelid data - final training data)
- _train_kmer.py_ (train and save the random forest model using the fasta file with preprocessed sequences)
- _kmer_based_Vhclass.py_ (generate predictions (human-like or camelid-like) using the trained model)
- _AbNativ_both_scores_validation2.py_ (Generate classification metrics from the AbNativ VH and VHH scores for the given sequence)


# **Generating predictions using provided trained model**
Download the provided model _rf_model_3mer.joblib_ and run the script called _kmer_based_Vhclass.py_ with the following input positional arguments:
- path to trained model
- number of aminoacids to encode as kmers (2 or 3, 3 is default, _note k=2 was not tested here, but will result in a prediciotn, k=4 will crash due to size of the feature vector_)
- path to fasta file with the data to be classified
- path to the .csv file were the predictions will be saved
- True or False flag: True if the data to be classified already has labels (validation datasets)


# **Training the model using provided public datasets**
To retrain the model using the provided datasets, use script _train_kmer.py_ with the following positional argumants:
- path to the provided training set (20k_fin_trainset_simple_filter.fasta)
- number of aminoacids to encode as kmers (2 or 3, 3 is default, _note k=2 was not tested here, but will result in a prediciotn, k=4 will crash due to size of the feature vector_)
- path to where to store the trained model in the .joblib format

# **List of the Provided Data (fasta files)**
The fasta files provided here were preprocessed (as described in the Application  Note). The sources for this data can be found in the Supplementary Material.

-  '20k_fin_training.fasta'   (compiled set of human and camelid sequences, used for model training)
- folder 'validation_sets' contains seven validation sets, used in this work
-  folder 'abnativ_scores_validation_sets' contains the outputs of the AbNativ tool analysis of all the validation sets. For validation set 1, the folder also contains the sequences with high and low VHH scores (used in Figure 1B)
